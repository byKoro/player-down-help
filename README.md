# Down Player Help

Down Player is an addon that will cause you to fall before dying; you can be revived or revive yourself.

## Features

The player can be revived when another player crouches near the fallen player.
The player can save themselves by consuming a golden apple. (It can be modified in "config.js")
Dying in lava and water kills the player instantly (It can be modified in "config.js")
Non-player entities cannot harm an injured player.
The player will automatically die after 30 seconds of bleeding. (It can be modified in "config.js")


Attention
The addon places a block on the player's head before they die, simulating a fall; this may cause minor inconveniences.
Other informations
This addon does not remove your world achievements.
This addon can be used with other addons.
The addon does not modify the player.json file.
